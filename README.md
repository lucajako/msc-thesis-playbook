# Master Thesis Guide

This repository is intended for MSc students who are starting, or are due to start, their thesis with our research group.

These guidelines have the purpose to explain how we work, how supervision is organized, and what is expected during the thesis.

## Disclaimer

This is the ideal process. It is highly likely that, whilst working on the dissertation, this process will not be followed due to a number of factors (e.g. difficulties with certain topics, an issue with reaching a consensus on a key point of the dissertation, public holidays, etc...).

## Start here

If you are a new student:

1. Read [Getting Started](docs/00-getting-started.md)
2. Read [How We Work](docs/01-how-we-work.md)
3. Understand the [Supervision Loop](docs/02-supervision-loop.md)
4. Read the [Weekly Workflow](docs/03-weekly-workflow.md)
5. Prepare your first weekly presentation using
   [Weekly Presentation](docs/04-weekly-presentation.md)
