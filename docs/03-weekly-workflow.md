# Weekly workflow

There is no a fixed workflow because everyone of us has his own method to work. What you will find here is a SUGGESTION on how to organize yourself during the time between one meeting and the next one.

```
Post meeting
│
├─ Review previous feedback
├─ Define objectives for the next update meeting
└─ Identify experiments/tasks

During the week
│
├─ Implementation
├─ Reading
├─ Experiments
├─ Analysis
└─ Document results continuously

Before meeting
│
├─ Clean results
├─ Update plots/tables
├─ Prepare presentation
├─ Write questions
└─ Push code

Weekly meeting
│
├─ What was the goal?
├─ What was done?
├─ What did we learn?
├─ What is blocking progress?
└─ What happens next?

After meeting (the same day)
│
├─ Write decisions
├─ Convert decisions into tasks
└─ Start next iteration
```

Do not organize work around “hours worked”...organize it around questions answered or what progress you have made in the meantime.
